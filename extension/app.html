Set up the downloader

Run MediaExtractor-Setup.exe from the project folder once, then check the connection.

Cloned from Git? Run Install Media Extractor.cmd instead.

Optional. Lets the local downloader read cookies from the browser you choose to sign in. Turn on only for posts you can access. Browser protections may prevent session access.

About quality

Video limits use the short edge, so portrait 1080 × 1920 fits 1080p. Instagram prefers a compatible H.264 source when available. Photos and audio are saved without automatic enhancement or volume changes.

Supported posts

YouTube, Instagram, X, Reddit, TikTok, Facebook, Pinterest and Threads. Scan the link, then select photos, videos, or both. An open matching post can supply fallback media when remote extraction is blocked. Hidden or unloaded slides may still be missing.

Get started.

One setup. Then just open and download.

Windows 10/11 · 64-bit
Brave, Google Chrome & Microsoft Edge

  1. Download Windows Setup

    One setup app for Windows 10/11 x64. No separate Node.js installation or source-code ZIP required.

    Download Windows Setup ↗

  2. Choose your browser and install

    Run MediaExtractor-Setup.exe, choose Chrome, Edge or Brave, then click Install. Required components are downloaded and verified automatically.

  3. Add the browser extension

    Use the wizard’s Open browser extensions button. Enable Developer mode, choose Load unpacked, and use Copy extension folder to select the installed folder. Then pin Media Extractor.

    Chrome
    chrome://extensions
    Edge
    edge://extensions
    Brave
    brave://extensions

  4. Save a post

    Open the popup, wait for Ready, paste a supported link, and click Scan link. Select the media you want, choose video quality, and click Download selected. Scans and downloads both appear in Activity.

No terminal stays open.

The installed app starts automatically. You can close the popup; keep the browser running until downloads finish.

Updating or seeing errors?

Finish downloads, close browsers using Media Extractor, and run the newest setup app. Your save folder is preserved.

Script or helper not found: load the installed extension folder shown by the wizard, then Reload. It is under %LOCALAPPDATA%\MediaExtractor\extension.

If an old copy from Downloads is still installed, remove that old entry after adding the installed copy. Saved media is not deleted.

Browser and system compatibility

The same Windows setup supports Google Chrome, Microsoft Edge and Brave. macOS, Linux, Firefox, Safari and mobile browsers are not supported yet.

Optional social-post login is off by default. When enabling it in Settings, choose the browser where you are signed in. Browser protections and site restrictions may still prevent session access.

Prefer the source ZIP?

Extract the full source ZIP, then run Install Media Extractor.cmd. It builds and opens the same wizard. The extracted folder is not needed after installing the stable copy.
