Set up the downloader

Run Install YouTube Downloader.exe from the project folder once, then check the connection.

Cloned from Git? Run Install YouTube Downloader.cmd instead.

Optional. Lets the local downloader read cookies from the browser you choose to sign in. Turn on only for posts you can access. Browser protections may prevent session access.

About quality

Video limits: 720p, 1080p, 1440p, or 4K. Best available has no cap. Photos save at the resolution provided by the site.

Supported posts

YouTube, Instagram, X, Reddit, TikTok and Facebook. Choose Video or Photos. Photos saves all images found in that post. Login-restricted content may not work.

Get started.

One setup. Then just open and download.

Windows 10/11 · 64-bit
Brave, Google Chrome & Microsoft Edge

  1. Install Node.js LTS

    Choose LTS, version 22 or newer, then Windows Installer (.msi), x64. Run it with the default options. Skip if already installed.

    Download Node.js LTS ↗

  2. Download the project

    Get the ZIP and use Extract All. Keep the extracted folder somewhere permanent, such as Documents.

    Download project ZIP ↗

  3. Run the one-time installer

    Close browsers using this extension. In the extracted project, double-click Install YouTube Downloader.cmd and wait for Setup complete. Despite the old filename, it installs all supported tools.

  4. Load and pin the extension

    Open your browser’s Extensions page, enable Developer mode, choose Load unpacked, and select the project’s extension folder—the one containing manifest.json. Then pin Media Extractor.

    Brave
    brave://extensions
    Chrome
    chrome://extensions
    Edge
    edge://extensions

  5. Save your first post

    Open the popup, wait for Ready, paste a supported link, and choose Video or Photos. Change the folder in Settings. Follow progress in Activity.

No terminal stays open.

The helper starts automatically. You may close the popup, but keep the browser running until downloads finish.

Starting over or seeing errors?

Remove the old copy on the Extensions page, close that browser, then follow the steps above. Saved media is not deleted.

Script-loading error: extract the whole ZIP; don’t move or delete its files. Clear old errors, then Reload. If it returns, remove and load the extension again.

Helper not found: rerun the installer from the same project folder you loaded, then reopen the browser.

Friends using another browser?

Windows versions of Brave, Chrome and Edge are supported. Each friend installs Node, the helper, and the extension on their own PC. The current installer does not support macOS, Linux, Firefox, Safari or mobile browsers.

For optional social-post login, choose the browser where you are signed in under Settings. Session access is off by default and can still be blocked by browser protections or site restrictions.

Updating later

Finish downloads, close browsers using Media Extractor, then run Update YouTube Downloader.cmd. For new extension code, download the latest project and reload the extension. If its folder moved, rerun the installer from the new location.
